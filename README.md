# BRAND NOTE — REBOOT 56 Web App

## 今回できること
- これまでの20ブランドを内蔵
- カテゴリー自動分類＋アイコン
- ブランド検索／カテゴリー絞り込み
- 訪問記録
- ちゃぴこ案のキャッチ
- JSONバックアップ
- **REBOOT 56へ送る**：ブランド訪問ログをMarkdownに書き出し、人生リブート計画のChatGPTへ渡せる
- PWA対応：Web公開後はスマホのホーム画面に追加可能

## Excelについて
Excelは初期データ移行元です。今後の更新はBRAND NOTEを本体にし、Excelはバックアップとして保管する想定です。

## ChatGPT「人生リブート計画」について
現時点では、カスタムWebアプリからChatGPTの既存Projectへ直接書き込む公開APIを前提にしていません。
代わりに「REBOOT 56へ送る」で学習ログを出力し、Projectへ渡せます。
将来、正式なAPI連携を組む場合は別途バックエンドを追加します。

## Web公開
GitHub Pages等にこのフォルダをそのまま公開すると、スマホからURLでアクセスできます。
公開後、スマホのブラウザの「ホーム画面に追加」でアプリのように起動できます。
